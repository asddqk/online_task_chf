РАЗРАБОТКА СИСТЕМЫ ХРАНЕНИЯ И РАЗБОР ЗАДАЧ ОЛИМПИАДНОГО УРОВНЯ ДЛЯ ШКОЛЬНИКОВ

Для работы с системой хранения и разбора задач были реализованы 6 классов:
1.	Main 
2.	ProblemLoader 
3.	Judge 
4.	SandboxManager 
5.	WebServer 
6.	WebProblemLoader

Архитектура программы:
Консольная ветка: Main (Контроллер UI) → ProblemLoader (Базовый загрузчик) → Judge (Ядро проверки) → SandboxManager (Инфраструктура).
Веб-ветка: WebServer (REST контроллер) → WebProblemLoader (Специализированный загрузчик) → Judge (То же ядро) → SandboxManager .
Обе ветки используют одинаковое ядро (Judge + SandboxManager), что обеспечивает единообразие проверки и переиспользование кода.
